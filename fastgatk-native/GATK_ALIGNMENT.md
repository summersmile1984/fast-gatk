# GATK 4.6.2.0 alignment ledger

The goal of `fastgatk-native` is semantic parity with the checked-in GATK
4.6.2.0 source for the core HaplotypeCaller, Mutect2, and GenotypeGVCFs
paths.  This file is an implementation ledger, not a feature checklist: an
entry is **aligned** only when the native control flow and data ownership have
been inspected against the cited GATK method and have an oracle exercising the
same contract.

## Fixed execution architecture

Source parity does not change the execution split.  C++ Host code owns the
irregular AssemblyRegion/EventMap/graph-topology/CIGAR/VCF state machines.
Kokkos owns k-mer counting and pruning, PairHMM, Smith-Waterman score batches,
and genotype numeric reductions.  Every Host SW traceback used by the caller
or dangling-end recovery first obtains its affine score through Kokkos and
checks score equality. A source-driven Host correction must not replace a
regular numeric kernel with serial host computation.

## Rules for changes

1. Start from a cited GATK source method and identify its state inputs and
   outputs before changing native logic.
2. Do not add a fixture-specific candidate exception as a substitute for an
   absent source-stage representation.
3. A test is an oracle only for the source boundary it actually exercises;
   record remaining unmodeled ownership explicitly.
4. Mark a row aligned only after source review and an end-to-end oracle cover
   its stated invariant.
